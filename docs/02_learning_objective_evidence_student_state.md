# Design 01A
# Learning Objective -> Evidence -> Student State

## Core Chain

```text
Course Material
      ↓
Learning Objective
      ↓
Teaching / Assessment
      ↓
Student Response
      ↓
Evidence Event
      ↓
Objective State
      ↓
Next Teaching Action
```

## Student Modeling Constitution

1. Concept != Learning Objective.
2. Learning objectives should describe observable behavior.
3. Bloom describes objective cognitive demand.
4. Bloom is not a fixed mastery ladder.
5. Student-state claims require evidence.
6. Evidence history is the source of truth.
7. Objective state is a derived estimate.
8. Assistance level affects evidence quality.
9. Novelty affects evidence quality.
10. Transfer affects evidence quality.
11. Self-report is weak evidence by default.
12. Student questions do not automatically mean weakness.
13. Misconceptions require repeated evidence before confirmation.
14. Students may dispute URPP inference.
15. State can increase or decrease.
16. Unknown / insufficient evidence is valid.
17. LLMs do not directly modify student state.
