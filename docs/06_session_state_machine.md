# Learning Session State Machine

Status: Planned.

```text
Open Session
      ↓
Determine Intent
      ↓
Set Session Objective
      ↓
Retrieve Prior State
      ↓
Optional Diagnostic
      ↓
Select Teaching Action
      ↓
Teach
      ↓
Student Response
      ↓
Extract Evidence
      ↓
Adapt
      ↓
Formative Assessment
      ↓
Transfer / Retrieval Check
      ↓
Session Summary
      ↓
Update Student State
      ↓
Recommend Next Action
```
